# Redot-cpp-Fsm

Hello everyone it is a basic Finite State Machine for Redot Game Engine in c++


FSM Architecture

Marine - Chracter Controller

StateMachine — Manages the active state and state changes.

PlayerState — Base interface for states.

IdleState — Idle behavior.

RunState — Running behavior.

JumpState — Jumping behavior.

FallState — Falling behavior.

Technologies used

C++

Cmake

Redot

Redot C++ GDExtension
